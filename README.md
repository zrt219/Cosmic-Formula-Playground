## 🎯 Educational Philosophy

Cosmic Formula Playground is designed to help curious learners understand astronomy, astrophysics, orbital mechanics, and plasma physics **visually and intuitively before confronting formal mathematical notation**.

```
  ┌─────────┐      ┌───────────┐      ┌────────────┐      ┌───────────┐
  │   SEE   │ ───► │   TOUCH   │ ───► │   CHANGE   │ ───► │   WATCH   │
  └─────────┘      └───────────┘      └────────────┘      └───────────┘
                                                                │
  ┌──────────┐      ┌─────────────┐      ┌────────────────┐     ▼
  │ PRACTICE │ ◄─── │  CALCULATE  │ ◄─── │   UNDERSTAND   │ ◄───┘
  └──────────┘      └─────────────┘      └────────────────┘
```

Every lesson presents concepts in a structured pedagogical order:
1. **Everyday intuition & ELI5 concept**
2. **Animated real-time vector simulation stage**
3. **Tactile parameter blocks and live sliders**
4. **Instant numerical recalculation and unit breakdown**
5. **Formal mathematical derivation (collapsible)**
6. **Adaptive practice challenges and timed missions**

## 🛠️ Architecture & Local Development

### Technology Stack
- **Pure Web Standards**: Vanilla ES Modules (`app.js`, `v3-model.mjs`, `formulas.mjs`) — Zero framework bloat.
- **Rendering**: Semantic SVG vectors, HTML5 Canvas, and MathJax/KaTeX math notation.
- **Routing**: HTML5 History API with static clean-URL fallback entrypoints.
- **Offline / PWA**: Service Worker (`sw.js`) with proactive cache lifecycle management and manifest support.
- **Styling**: Responsive modern Airy CSS tokens (`--indigo`, `--coral`, `--emerald`, `--sky`).

### Run Locally
```bash
# Clone the repository
git clone https://github.com/zrt219/Cosmic-Formula-Playground.git
cd Cosmic-Formula-Playground

# Start a local static HTTP server
npx serve .
# or
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.

### Verification & Test Suite
```bash
# Run syntax checks, QA invariants, and DOM selector tests
npm run check
```
